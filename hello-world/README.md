# Hello World

10 种编程语言的 Hello World。

| 语言 | 文件 | 运行方式 |
|---|---|---|
| Python | [python/hello.py](python/hello.py) | `python hello.py` |
| C | [c/hello.c](c/hello.c) | `gcc hello.c -o hello && ./hello` |
| C++ | [cpp/hello.cpp](cpp/hello.cpp) | `g++ hello.cpp -o hello && ./hello` |
| Java | [java/Hello.java](java/Hello.java) | `javac Hello.java && java Hello` |
| JavaScript | [javascript/hello.js](javascript/hello.js) | `node hello.js` |
| TypeScript | [typescript/hello.ts](typescript/hello.ts) | `npx tsx hello.ts` |
| Go | [go/hello.go](go/hello.go) | `go run hello.go` |
| Rust | [rust/hello.rs](rust/hello.rs) | `rustc hello.rs && ./hello` |
| C# | [csharp/Hello.cs](csharp/Hello.cs) | `dotnet script Hello.cs`，或放进 `dotnet new console` 项目里运行 |
| Ruby | [ruby/hello.rb](ruby/hello.rb) | `ruby hello.rb` |
